# kr1_math_-for_programming

Контрольная работа №1 по курсу «Математика для программирования».

Репозиторий содержит решённые задачи по линейной алгебре: системы линейных
алгебраических уравнений (СЛАУ), операции с матрицами, определители,
собственные значения и векторы, жорданова форма, квадратичные формы и
кривые второго порядка. Все решения выполнены в Jupyter Notebook с
использованием Python (SymPy, NumPy, Matplotlib) — с точными символьными
вычислениями там, где это возможно, и с численными методами для
матриц больших размеров.

## Содержимое

Основной файл:

- **`Листок_1_решения-2-2.ipynb`** — ноутбук с полными решениями всех задач
  листка №1 (1.1–1.20). Каждая задача оформлена в виде отдельной ячейки:
  постановка, метод решения, код и ответ.

## Используемые инструменты

- **Python 3.12**
- **SymPy** — точные символьные вычисления: `Matrix.rref()`, `det()`,
  `charpoly()`, `jordan_form()`, `eigenvects()`, `GramSchmidt()`,
  `diagonalize()`, `solve()`
- **NumPy** — численные методы для больших матриц: `linalg.det`,
  `linalg.eig`, `linalg.eigvalsh`, `linalg.matrix_power`, `kron`
- **Matplotlib** — визуализация (матрица биномиальных коэффициентов mod 2,
  матрица Адамара `H_64`)

## Как запустить

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/katshuuu/kr1_math_-for_programming.git
   cd kr1_math_-for_programming
   ```

2. Установить зависимости:
   ```bash
   pip install sympy numpy matplotlib jupyter
   ```

3. Открыть ноутбук:
   ```bash
   jupyter notebook "Листок_1_решения-2-2.ipynb"
   ```

4. Выполнить все ячейки: **Cell → Run All**.

## Примечания

- Для задач 1.6–1.9 (матрицы больших размеров) полный перебор невозможен,
  поэтому используются численные методы и аналитические формулы
  (например, формула определителя для «диагональ + возмущение 2×2 блока»).
- Ответы в конце каждой задачи продублированы в текстовых ячейках
  в виде формул LaTeX.
- Все вычисления воспроизводимы: для случайных алгоритмов
  (задача 1.6) зафиксирован `seed` генератора случайных чисел.
